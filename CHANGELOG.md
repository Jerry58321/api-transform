# Changelog

All notable changes to API Transform are documented in this file.

The format follows the spirit of Keep a Changelog, and this project uses
semantic versioning for public releases.

## [Unreleased]

### Added

- GitHub Actions test workflow for supported Laravel generations.
- README badges for CI status, Packagist version, downloads, and license.
- Security and contribution policies.
- Bug report, feature request, and pull request templates.

## [3.1.0] - 2026-06-01

### Added

- Laravel 11 and 12 compatibility.
- PHPUnit data provider compatibility for newer PHPUnit releases.
- MIT license file.
- Composer scripts for tests and coverage.

### Changed

- Expanded supported Symfony and Illuminate component constraints for modern
  Laravel versions.
- Refreshed package metadata, README documentation, and MIT license.

### Fixed

- Updated exception constructors to avoid nullable parameter deprecations on
  newer PHP versions.
